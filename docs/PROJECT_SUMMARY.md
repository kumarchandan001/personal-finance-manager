# PROJECT SUMMARY: FINTELIA

An AI-powered behavioral personal finance management platform.

## Completed Phases
- **Phase 0:** Flutter + FastAPI architectural scaffolding.
- **Phase 1:** Core Authentication (Access/Refresh Tokens) and basic Transaction CRUD.
- **Phase 2:** Financial Analytics (overview, trends, categories), Budget Intelligence (progress, projections), Goal Tracking (progress, completion), and Rule-based Financial Insights. 

## Tech Stack
- **Frontend:** Flutter, Riverpod, GoRouter, Material 3, fl_chart, Dio.
- **Backend:** FastAPI, SQLAlchemy, asyncpg, PostgreSQL, Alembic.
- **Auth:** Custom JWT + Firebase fallback (optional).
